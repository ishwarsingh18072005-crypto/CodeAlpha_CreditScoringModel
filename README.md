# CodeAlpha Credit Scoring Model

## Project Overview

This project develops a machine learning model for predicting creditworthiness using financial and demographic information.

## Objective

The objective is to classify applicants into:

- Good Credit
- Bad Credit

## Dataset

The project uses the German Credit dataset available through OpenML.

## Machine Learning Algorithms

- Logistic Regression
- Random Forest Classifier

## Data Preprocessing

- Missing value handling
- Numerical feature scaling
- Categorical feature encoding
- Train-test splitting

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib
